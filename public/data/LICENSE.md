This is a bounded snapshot of named food venues with city and street address tags
in New Jersey, New York, and California. California uses venues explicitly tagged
with a California state address. It is not an exhaustive directory or an
independent verification of current operations, opening hours, dietary claims,
menu prices, or venue ownership. The JSON includes the extraction timestamp,
source database timestamps, state selection queries, stable OSM IDs, coordinates,
and source-tagged categories. No reviews, ratings, prices, or restaurant images
were generated. The app provides source links and clearly separates receipt-backed
review evidence from directory metadata.

The directory data license does not change the license of the application code.
